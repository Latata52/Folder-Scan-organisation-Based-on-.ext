## OVERVIEW
This Script organizes all files in a folder, by extension to a media type/
Once all extensions are grouped, folders of their designated media type are created and implemented.

## FEATURES
- User specified folder based on the path 
- Scan entire folder
- Group by extension
- Creates child-folders to the specified folder to organise by media based on extension
- Composes report on the amount of files scanned and grouped together.
